# Bootstrap Portfolio Project

A responsive portfolio website built from scratch using Bootstrap 5 framework.

## Features

- **Responsive Navigation Bar**: Built with Bootstrap navbar component and toggleable mobile menu
- **ScrollSpy**: Automatically updates active navigation links based on scroll position
- **Hero Section**: Eye-catching landing section with call-to-action buttons
- **About Section**: Introduction with technology badges
- **Projects Gallery**: Six project cards using Bootstrap card component with hover effects
- **Modal Windows**: Detailed project information displayed in Bootstrap modals
- **Contact Form**: Fully styled contact form using Bootstrap form components
- **Responsive Design**: Mobile-first design using Bootstrap's grid system and breakpoints
- **Smooth Scrolling**: Enhanced user experience with smooth page navigation

## Technologies Used

- HTML5
- CSS3 (minimal custom styles)
- Bootstrap 5.3.2
  - CSS Framework
  - JavaScript components (modals, navbar, scrollspy)
- Bootstrap Icons 1.11.1
- Vanilla JavaScript for interactivity

## Bootstrap Components Utilized

1. **Navbar**: Fixed-top navigation with responsive collapse
2. **ScrollSpy**: Active menu link tracking on scroll
3. **Cards**: Project showcase with images, text, and badges
4. **Buttons**: Call-to-action and interaction buttons
5. **Badges**: Technology tags and labels
6. **Modals**: Popup windows for detailed project information
7. **Forms**: Contact form with inputs, textarea, and labels
8. **Grid System**: Responsive layout with rows and columns
9. **Utilities**: Spacing, alignment, and color utilities

## How to Run

1. Clone the repository
2. Open `index.html` in a web browser
3. No build process required - Bootstrap is loaded via CDN

## Responsive Breakpoints

The website is fully responsive and adapts to different screen sizes:

- **Desktop**: Full layout with sidebar navigation
- **Tablet** (≤ 992px): Adjusted grid layout, collapsed navigation
- **Mobile** (≤ 768px): Single column layout, hamburger menu
- **Small Mobile** (≤ 576px): Optimized for small screens
