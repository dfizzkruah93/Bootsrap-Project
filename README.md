# Bootstrap Portfolio Website

A modern, responsive portfolio website built with Bootstrap 5. This project showcases a professional portfolio with multiple sections including About, Skills, Portfolio, and Contact.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices (mobile, tablet, desktop)
- **Modern UI**: Clean and professional design using Bootstrap 5
- **Smooth Animations**: Engaging animations and transitions throughout the site
- **Interactive Navigation**: Fixed navbar with smooth scrolling to sections
- **Portfolio Gallery**: Showcase your projects with a card-based layout
- **Skills Section**: Display your technical skills with progress bars
- **Contact Form**: Functional contact form for visitor inquiries
- **Social Media Links**: Easy access to your social media profiles

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5.3.0
- Bootstrap Icons 1.10.0

## Sections

1. **Navigation Bar**: Fixed top navigation with links to all sections
2. **Hero Section**: Eye-catching header with call-to-action buttons
3. **About Section**: Personal introduction with profile image
4. **Skills Section**: Technical skills displayed with cards and progress bars
5. **Portfolio Section**: Project showcase with cards and badges
6. **Contact Section**: Contact form and contact information
7. **Footer**: Social media links and copyright information

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/dfizzkruah93/Bootsrap-Project.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Bootsrap-Project
   ```

3. Open `index.html` in your web browser:
   - Double-click the file, or
   - Right-click and select "Open with" your preferred browser, or
   - Use a local server (recommended):
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx http-server
     ```

4. View the website at `http://localhost:8000` (if using a local server)

## Customization

### Personalizing Content

1. **Update Personal Information**: Edit `index.html` to change:
   - Name and title in the hero section
   - About me description
   - Skills and expertise
   - Portfolio projects
   - Contact information

2. **Replace Images**: 
   - Update placeholder images with your own images
   - Change `src` attributes in the `<img>` tags

3. **Modify Colors**: 
   - Edit `css/style.css` to change the color scheme
   - Main gradient: `.hero-section` background
   - Update Bootstrap theme colors as needed

4. **Add More Projects**: 
   - Duplicate portfolio card HTML in `index.html`
   - Update project details, images, and badges

### Styling

- Custom styles are in `css/style.css`
- Bootstrap classes can be modified directly in `index.html`
- Color scheme uses a purple gradient by default

### Functionality

- JavaScript functionality is in `js/script.js`
- Includes smooth scrolling, form validation, and animations
- Easily extendable for additional features
